# 🚀 C# Fundamentals & CS50 Playground

Uma coleção de exercícios, práticas e anotações criadas durante meus estudos iniciais de programação e C# (inspirado pelos conceitos do CS50 de Harvard). 
Este repositório serve como um laboratório pessoal para testar lógica de programação, sintaxe da linguagem e algoritmos fundamentais.

## 📁 Arquivos e Atividades

Aqui está um resumo do que cada arquivo neste repositório representa e faz:

| Arquivo | Descrição | Conceitos Abordados |
| :--- | :--- | :--- |
| **Arrays.cs** | Trabalhando com coleções de dados. Criação, inicialização e modificação de arrays. | Arrays, Indexação |
| **BetterCalculator.cs** | Uma calculadora mais avançada que recebe dois números e um operador lógico (+, -, /, *) e realiza a operação correta. | If/Else Statements, Operadores Matemáticos |
| **DataTypes.cs** | Exemplos práticos dos tipos de dados primitivos do C# (strings, chars, inteiros, decimais, booleanos). | Tipos Primitivos, Variáveis |
| **IfPlayground.cs** | Um script interativo que compara três números para encontrar o maior deles usando condicionais, com direito a uma tela de carregamento animada no terminal. | Condicionais Aninhadas, Thread.Sleep, Console.Clear |
| **IfStatement.cs** | Prática de lógica booleana avaliando duas variáveis (isFemale e isShort) para retornar diferentes respostas no console. | Booleans, If/Else, Lógica AND (&&) |
| **MadLib.cs** | O clássico jogo de palavras "Mad Libs"! Pede ao usuário três palavras diferentes e monta um poema engraçado na tela. | Inputs (Console.ReadLine), Concatenação de Strings |
| **Methods.cs** | Criação de funções personalizadas no C#. Inclui a chamada de um método que recebe parâmetros (nome e idade). | Métodos (Funções), Parâmetros, Void |
| **Numbers.cs** | Operações matemáticas e uso da biblioteca matemática nativa (Math) para raiz quadrada, potência, arredondamentos e valores absolutos. | Math Class, Operadores Aritméticos |
| **SimpleCalculator.cs** | A primeira calculadora! Recebe dois números do usuário e simplesmente os soma. Prática de conversão de tipos de dados. | Casting (Convert.ToDouble) |
| **Strings.cs** | Estudo de manipulação de textos. Cortando strings e utilizando caracteres de escape (como \n e \"). | String.Substring, Escape Characters |
| **SwitchStatement.cs** | Uma função que converte um número de 0 a 6 para o dia da semana correspondente, utilizando a estrutura de múltipla escolha. | Switch/Case, Return |
| **UserInput.cs** | Coletando dados básicos do usuário no terminal (nome e idade) e devolvendo uma saudação customizada. | I/O, Variáveis de texto |
| **anilla.cs** | Primeiro contato com variáveis e atualização de dados. Uma pequena história sobre um gato chamado Vanilla! | Declaração de Variáveis, Reatribuição |

*Desenvolvido com dedicação durante meus estudos de lógica e programação C#.*
